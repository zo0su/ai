산탄데르 은행 고객 만족 데이터셋

1. 머신러닝 교육에 활용되는 주요 이유
실무에서 발생하는 데이터의 현실적 문제점들을 고루 갖춘 최적의 훈련용 데이터

• 극심한 클래스 불균형 경험
◦ 전체 데이터 중 불만족 고객(Target=1)의 비율이 약 4%에 불과함.
◦ Accuracy(정확도)만 높이는 모델링은 무의미함.
◦ 기준 모델에서 정확도 착시를 확인한 뒤, 추가 활동에서 ROC-AUC를 계산하기
◦ ROC-AUC: ROC 곡선 아래의 면적(Area Under the Curve)으로, 값이 1에 가까울수록 모델의 구분 능력이 우수함을 의미함.

• 익명화된 피처 전처리
◦ 피처가 모두 익명화되어 있어 배경 지식에 의존하기 어려움.
◦ 변수 중요도, 상관관계 분석, 불필요한 피처 제거 등 전처리 테크닉이 필요함.

• 다양한 노이즈와 특이값 처리
◦ -999999와 같은 극단적인 결측치, var38처럼 특정 값에 20% 가까이 몰려 있음.

2. 데이터의 유의미성
• 실제 금융권 이탈, 불만족 예측 문제
◦ 금융 서비스에서 고객의 불만족이나 이탈은 드물게 발생하지만 회사 수익에 치명적임.
• 과적합 방지 기법 습득
◦ 피처의 수는 많고 타겟 신호는 약해서 모델이 쉽게 과적합됨.

교수-학습 설계 의도 & 목표
높은 정확도가 왜 쓸모없는 결과가 될 수 있는지를 숫자로 확인하고 평가지표를 고르는 판단까지 배우게 되며, 산탄데르 자료는 그 판단에 유용한 자료임.

  • ‘성능이 올랐다’로 끝내지 않고, 재현율과 정밀도 중 우선할 것을 판단할 필요성이 제기됨.

[의미]

  • 정확도 0.96라는 숫자는 불만족 재현율 0에서 나왔음을 확인함으로써 지표를 의심해야 함.
  • 표준화와 클래스 가중치를 넣으면 같은 데이터에서 정확도는 내려가고 재현율은 올라감. 은행이 이탈 고객을 놓치는 손실과 만족 고객에게 비용을 쓰는 손실을 비교할 수 있음.

서포트 벡터 머신 (SVM)

  • 데이터 간 간격을 극대화하는 최적의 경계선 찾
  • 핵심 원리: 클래스 간의 거리(마진)를 최대화하는 결정 경계(Hyperplane)를 탐색함.
  • 학습 방식: 경계에 인접한 데이터인 서포트 벡터를 기준으로 여백을 최대한 확보함.
  • 주요 용도: 고차원 데이터 분류, 이미지 인식, 텍스트 카테고리화
  • 커널 함수
  • linear: 기본 선형 경계 (직선/평면)
  • rbf (Radial Basis Function): 복잡한 곡선/원형 형태의 비선형 경계 형성
  • poly: 다항식 경계 (2차, 3차 곡선 등)

분류 모델의 성능 평가 지표(혼동행렬Confusion Matrix)

  • 1에 가까울수록 예측 정확도가 높음.
  • 정확도(Accuracy): 전체 예측 중 올바르게 예측한 비율
  • 정밀도(Precision): 양성으로 예측한 것 중 실제 양성인 비율
  • 재현율(Recall): 실제 양성인 것 중 양성으로 예측해 낸 비율
  • F1 Score: 정밀도와 재현율의 조화평균값
구분정밀도 (Precision)재현율 (Recal)
개념모델이 양성이라고 예측한 것 중 진짜 양성의 비율실제 양성인 것 중 모델이 맞춘 비율
공식Precision=TP+FPTP​Recall=TP+FNTP​
핵심 질문"모델이 양성이라고 말했을 때, 얼마나 믿을 수 있는가?""실제 양성 데이터를 놓치지 않고 얼마나 잘 찾아내는가?"
실제 예시스팸 메일 분류: 일반 메일을 스팸으로 오진(FP)하면 중요한 메일을 못 읽게 되므로 정밀도가 중요합니다.암 환자 진단 / 사기 탐지: 실제 암 환자를 정상으로 오진(FN)하면 생명이 위험해지므로 재현율이 극도로 중요합니다.

ROC 곡선 (Receiver Operating Characteristic Curve)

임계값을 1.0에서 0.0까지 연속적으로 내리면서, X축(거짓 양성률)과 Y축(참 양성률)의 변화를 점으로 찍어 이어 만든 곡선

  • 완벽한 모델: 거짓 양성(X축)은 전혀 만들지 않으면서 참 양성(Y축)을 100% 맞추는 모델임. 그래프가 왼쪽 위 꼭짓점(0, 1)을 향해 바짝 붙는 형태가 됨.
  • 동전 던지기(무작위 추측) 모델: 아무런 학습을 하지 않고 무작위로 예측하면 대각선 주황색 점선 형태가 됨.

AUC (Area Under the ROC Curve)

AUC는 ROC 곡선 아래쪽의 전체 면적(넓이)을 뜻함. 곡선 형태를 매번 눈으로 비교하기 어렵기 때문에, 모델의 성능을 하나의 숫자로 요약한 것임.

  • AUC = 1.0: 완벽한 분류기 (오진이 전혀 없음)
  • AUC = 0.8 ~ 0.9: 매우 우수한 성능
  • AUC = 0.7 ~ 0.8: 무난하고 괜찮은 성능
  • AUC = 0.5: 동전 던지기 수준 (예측 능력이 전혀 없음)

1.7.1. SVC(결정 경계, C, gamma, degree)

  • 결정 경계 종류
    1. 방사기저함수-무한한 차원의 점으로 변환(kernel='rbf'), 기본값
    2. 선형-2차원-선(kernel='linear')
    3. 다항식-다차원-평면(kernel='poly')
    4. 시그모이드(kernel='sigmoid')
  • C 파라미터: C값이 적을수록 소프트마진(마진이 커짐), C값이 클수록 하드마진(마진이 작아짐.)
  • gamma 파라미터: 결정 경계를 얼마나 유연하게 그을 것인지 결정함. gamma값이 적을수록 결정 경계를 직선에 가깝게 그음. ’scale’은 자동 계산하는 기본값임. kernel='linear'에서는 gamma가 경계에 쓰이지 않으므로 이번 기준 모델에는 넣지 않음.
  • degree 파라미터: kernel='poly'인 경우 차원을 나타냄. 기본값은 3차원

1.8. fit 함수: 학습(X_train, y_train)

  • 화면에는 gamma='scale'이 들어 있음. kernel='linear'에서는 gamma가 쓰이지 않으므로, 노트북의 기준 모델은 C=1.0, kernel='linear', random_state=156만 지정함. 학습은 여기서 한 번만 하고, 예측 셀에서 다시 fit하지 않음.

Step 1: 모델의 '실패' 원인 찾기

  • 활동: Accuracy 96%만 보고 ‘성공했다’고 생각하기 쉽지만 재현율(Recall)이 0임.
  • 효과: 데이터 불균형 환경에서 정확도(Accuracy) 지표가 가진 위험성과 착시 현상을 확인할 수 있음 .
  • classification_report는 불만족을 한 건도 예측하지 않으면 UndefinedMetricWarning을 냄. 정밀도를 0으로 채운 경고이며, 모델이 불만족 클래스를 만들지 않았다는 신호임.

Step 2: 불균형 데이터 해결 및 모델 재학습

  • 활동: class_weight='balanced' 를 지정하면 scikit-learn은 전체 데이터 수와 각 클래스의 샘플 수를 바탕으로 아래 공식에 따라 가중치를 자동으로 계산함.
  • 다수 클래스 (0): 샘플 수가 많으므로 작은 가중치가 부여됨. (틀려도 가벼운 벌점)
  • 소수 클래스 (1): 샘플 수가 적으므로 큰 가중치가 부여됨. (틀리면 무거운 벌점)
  • 소수 클래스 감지율 상승: 불만족(1) 데이터 하나를 틀렸을 때 받는 손실(Loss)을 크게 늘려, 모델이 소수 클래스를 더 적극적으로 찾아내도록 학습함.
  • 재현율(Recall) 향상: 진짜 불만족한 고객을 놓치지 않고 찾아내는 성능이 크게 올라감. 대신 소수 클래스를 더 촘촘하게 찾다 보니 정상 데이터(0)를 불만족(1)으로 잘못 분류하는 경우도 함께 늘어나 정밀도(Precision)는 다소 낮아질 수 있음.
  • 표준화: StandardScaler는 학습 세트에만 fit하고, 테스트 세트는 transform만 함. 0/1 변수와 횟수 변수의 계수 크기를 비교하려면 단위를 먼저 맞춰야 함.
  • 평가: 혼동행렬, classification_report, roc_auc_score를 함께 봄. 결정 점수는 decision_function을 씀. 정확도가 내려가도 불만족 재현율과 ROC-AUC를 같이 적음. 결과 숫자는 노트북을 실행해 확인함.

[코랩 입력 17]

from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score

# 1. 데이터 표준화 (학습 세트에만 fit, 테스트 세트는 transform만 적용)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 2. 불균형 데이터 처리를 위한 SVC 모델 생성 (class_weight='balanced')
svc_balanced = SVC(
    C=1.0,
    kernel='linear',
    class_weight='balanced',
    random_state=156
)

# 3. 모델 학습 및 예측
svc_balanced.fit(X_train_scaled, y_train)
pred_balanced = svc_balanced.predict(X_test_scaled)

# 4. 결정 점수(decision_function) 계산 (ROC-AUC 평가용)
decision_scores = svc_balanced.decision_function(X_test_scaled)

# 5. 결과 평가 및 출력
print("=== 혼동 행렬 (Confusion Matrix) ===")
print(confusion_matrix(y_test, pred_balanced))

print("\n=== 분류 리포트 (Classification Report) ===")
print(classification_report(y_test, pred_balanced))

print("\n=== ROC-AUC 점수 ===")
roc_auc = roc_auc_score(y_test, decision_scores)
print(f"ROC-AUC Score: {roc_auc:.4f}")

① 필요 라이브러리 임포트
• StandardScaler: 데이터 피처들의 단위를 평균 0, 표준편차 1로 맞추기 위해 사용함.
• SVC: 서포트 벡터 머신 분류 모델을 사용함.
• classification_report, confusion_matrix, roc_auc_score: 모델의 예측 성능을 다양한 관점에서 평가하기 위한 지표 함수임.

② 데이터 표준화 (StandardScaler)

  • fit_transform: 학습 데이터(X_train)의 평균과 표준편차를 학습함과 동시에 데이터를 표준화 변환함.
  • transform: 테스트 데이터(X_test)는 학습 데이터에서 얻은 기준으로 변환만 수행함.(데이터 누수 방지)

③ 모델 생성 및 불균형 데이터 처리

  • kernel='linear': 선형 결정 경계를 사용함.
  • class_weight='balanced': 가장 중요한 옵션으로, 수가 적은 소수 클래스(불만족, 1)에 자동으로 가중치를 더 많이 부여하여 모델이 소수 클래스를 놓치지 않도록 학습시킴.

④ 모델 학습, 예측 및 결정 점수 계산

  • fit()으로 표준화된 데이터를 학습시킨 뒤 predict()로 클래스(0 또는 1)를 예측함.
  • decision_function()은 확신도(경계선과의 거리) 점수를 반환하며, 이는 ROC-AUC 점수를 계산할 때 사용됨.

혼동 행렬 (Confusion Matrix)

정상(0) 예측: 14,602개 중 10,235개 정답, 4,367개 오답 (불만족으로 잘못 예측)

불만족(1) 예측: 602개 중 391개 정답, 211개 오답 (놓침)

의미: 기존 모델은 불만족(1)을 0개 맞혔으나, class_weight='balanced' 적용 후 602명 중 391명의 불만족 고객을 찾아냄.

분류 리포트 (Classification Report)

재현율 (Recall - 0.65 / 65%):
• 실제 불만족 고객 602명 중 65%를 성공적으로 감지해냈음을 나타냄. 이전보다 불만족 고객 탐지 능력이 획기적으로 향상됨.

정밀도 (Precision - 0.08 / 8%):
• 모델이 불만족이라고 예측한 사람들 중 실제 불만족이었던 비율임. 모델이 불만족 고객을 놓치지 않으려고 촘촘하게 잡다 보니 정상 고객도 불만족으로 오인하여 정밀도는 낮아짐.

f1-score (0.15):
• 정밀도와 재현율의 조화평균

ROC-AUC 점수: 0.7018

  • 0.7018: 모델의 전체적인 분류 식별 능력이 무작위 찍기(0.5)보다 훨씬 우수한 약 70% 수준의 구분 능력을 갖추었음을 보여줌.
  • 기존 모델이 불만족 고객을 한 명도 맞히지 못했던 문제점이 class_weight='balanced' 조치 덕분에 해결되어, 실제 불만족 고객의 65%를 감지할 수 있게 된 의미 있는 개선 결과임.

Step 3: 표준화와 class_weight 이후의 계수로 요인 읽기

  • 이전 단계에서 문제점으로 지적되었던 두 가지 한계가 표준화(StandardScaler)와 클래스 가중치(class_weight='balanced')를 통해 모두 해결되었기 때문에, 비로소 coef_ 계수를 올바르게 해석할 수 있는 조건이 갖춰짐.
  • 이제는 계수의 절댓값(Abs_Coefficient)이 클수록 ‘불만족 예측에 실제로 영향력이 큰 주요 피처’라고 공정하게 판단할 수 있음.
