1.7.1. SVC(결정 경계, C, gamma, degree)

  • 결정 경계 종류
    1. 방사기저함수-무한한 차원의 점으로 변환(kernel='rbf'), 기본값
    2. 선형-2차원-선(kernel='linear')
    3. 다항식-다차원-평면(kernel='poly')
    4. 시그모이드(kernel='sigmoid')
  • C 파라미터: C값이 적을수록 소프트마진(마진이 커짐), C값이 클수록 하드마진(마진이 작아짐.)
  • gamma 파라미터: 결정 경계를 얼마나 유연하게 그을 것인지 결정, gamma값이 적을수록 결정 경계를 직선에 가깝게 그음. =’scale’은 자동 계산하는 기본값임.
  • degree 파라미터: kernel='poly'인 경우 차원을 나타냄. 기본값은 3차원

1.10. SVM 예측 정확도 출력

클래스 불균형(Class Imbalance) 심각한 예측 편향을 보임.

1. 혼동 행렬 (Confusion Matrix)

  • [14602, 0]: 실제 0인 데이터 14,602개 중 14,602개 모두 0으로 예측함.
  • [602, 0]: 실제 1인 데이터 602개 중 단 1개도 맞히지 못하고 모두 0으로 예측함.
  • 결론: SVM 모델이 학습을 포기하고 모든 데이터를 '0'으로만 찍고 있는 상태임.

2. 분류 보고서 (Classification Report)

  • 클래스 0 (만족/음성): support가 14,602개로 전체의 대부분을 차지함. 모델이 모두 0으로 예측했으므로 재현율(recall)은 1.00(100%)을 기록함.
  • 클래스 1 (불만족/양성): support가 602개 존재하지만, 모델이 맞힌 개수가 0개이므로 precision, recall, f1-score 모두 0.00임.
  • 착시 효과 (accuracy = 0.96): 전체 15,204개 중 14,602개를 맞혀 정확도가 96%로 매우 높아 보이지만, 이는 모델이 잘 예측해서가 아니라 0번 데이터가 압도적으로 많아서 발생하는 '정확도의 착시 현상'임.
구분주요 지표/설정도메인 맥락 반영 수정 및 해석
모델 설정kernel='linear'370개의 고차원 피처 데이터에 대해 단순 선형 경계(Linear Hyperplane)만 적용하여 불만족(1) 레이블을 세밀하게 분리해내지 못함.
정확도96% (0.96)고객의 약 96%가 '만족(0)' 상태인 불균형 데이터셋 특성상, 모델이 모든 고객을 '만족(0)'으로 단순 예측해도 96% 정확도가 달성되는 착시 발생
비즈니스 영향recall = 0.00 실제 은행 입장에서 반드시 찾아내어 이탈을 막아야 할 '불만족 고객(1)'을 단 한 명도 감지하지 못해 비즈니스 유용성이 0에 가까운 상태

[결과로 본 이 활동의 문제점]

  • 불만족 요인 추출 불가능: 단순 선형 SVM(kernel='linear') 모델이 모두 0으로 예측하므로, 어떤 피처가 고객 불만족에 영향을 주었는지 알 수 없음.
  • 익명화된 피처 이름의 한계: 데이터셋의 컬럼명이 var3, ind_var30, num_meses_var5_ult3 등 암호화되어 있어, 비즈니스적 대책(예: ‘앱 응답 속도 개선’, ‘대출 금리 인하’ 등)을 도출하기 어려움.
  • 평가 지표의 착시: '정확도 96%'라는 숫자에 속아 모델이 잘 작동한다고 오해하기 좋은 구조임.

[추가 활동]

Step 1: 모델의 '실패' 원인 찾기

  • 활동: Accuracy 96%만 보고 ‘성공했다’고 생각하기 쉽지만 재현율(Recall)이 0임.
  • 효과: 데이터 불균형 환경에서 정확도(Accuracy) 지표가 가진 위험성과 착시 현상을 확인할 수 있음 .

Step 2: 불균형 데이터 해결 및 모델 재학습

  • 활동: class_weight='balanced' 를 지정하면 scikit-learn은 전체 데이터 수와 각 클래스의 샘플 수를 바탕으로 아래 공식에 따라 가중치를 자동으로 계산함.
  • 다수 클래스 (0): 샘플 수가 많으므로 작은 가중치가 부여됨. (틀려도 가벼운 벌점)
  • 소수 클래스 (1): 샘플 수가 적으므로 큰 가중치가 부여됨. (틀리면 무거운 벌점)
  • 소수 클래스 감지율 상승: 불만족(1) 데이터 하나를 틀렸을 때 받는 손실(Loss)을 크게 늘려, 모델이 소수 클래스를 더 적극적으로 찾아내도록 학습함.
  • 재현율(Recall) 향상: 진짜 불만족한 고객을 놓치지 않고 찾아내는 성능이 크게 올라감. 대신 소수 클래스를 더 촘촘하게 찾다 보니 정상 데이터(0)를 불만족(1)으로 잘못 분류하는 경우도 함께 늘어나 정밀도(Precision)는 다소 낮아질 수 있음.

Step 3: 불만족 요인(피처 중요도) 추출

  • 활동: 트리 모델의 feature_importances_로 불만족(1)을 예측하는 데 가장 결정적인 영향을 미친 상위 피처 5~10개를 정렬하기.
  • 효과: 어떤 데이터(예: 특정 계좌 잔액 num_var30, 거래 횟수 등)가 불만족 분류의 핵심 원인인지 기술적으로 파악하기

Step 4: 선형 SVM 모델에서 계수(Coefficient) 기반 요인 추출

kernel='linear' 설정의 SVM 모델은 각 피처에 부여된 가중치(계수)의 절대값이 클수록 분류에 중요한 영향을 미친 것으로 해석함.

# SVM 모델의 계수(coef_) 추출 (1차원으로 변환)
coefficients = svc.coef_.reshape(-1)

# 피처명과 계수 값을 데이터프레임으로 변환
feature_names = cust_feature.columns
svm_importance = pd.DataFrame({
    'Feature': feature_names,
    'Coefficient': coefficients,
    'Abs_Coefficient': np.abs(coefficients)
}).sort_values(by='Abs_Coefficient', ascending=False)

# 불만족(1) 분류에 가장 큰 영향을 준 상위 10개 출력
print("=== [SVM] 불만족 분류 영향력 상위 10개 피처 ===")
print(svm_importance[['Feature', 'Coefficient', 'Abs_Coefficient']].head(10))

선형 SVM 모델은 변수에 가중치(계수)를 곱해서 ‘불만족(1)’인지 ‘만족(0)’인지를 판단함.

1. 점수표 비유로 이해하기
모델이 고객의 불만족 여부를 계산하는 일종의 ‘불만족 점수 계산기’임.
• 가중치(Coefficient) = 각 항목당 부여되는 점수
• 입력값(Feature) = 고객의 해당 데이터 수치총 불만족 점수 = (변수A × A점수) + (변수B × B점수) + : 총점이 높으면 모델은 고객을 불만족(1)으로 판단함.

2. 영향력이 크다는 것의 의미
• 절대값(Abs_Coefficient) 해당 변수가 1단위 변할 때 총점수를 가장 크게 흔듦.
• 양수(+) 계수 (ind_var30 = 0.000877) 값이 커질수록 불만족 점수를 플러스(+)시킴.
• 음수(-) 계수 (num_var30 = -0.000104) 값이 커질수록 불만족 점수를 마이너스(-)시킴.

따라서, Abs_Coefficient 기준으로 정렬했을 때 ind_var30이 맨 위에 나온 것은, ‘이 고객이 불만족(1)인지 판단할 때 가장 눈여겨보고 점수를 크게 반영하는 핵심 변수’임을 의미함.
