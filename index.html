[실습] 전복 순살의 무게를 맞혀 봐.

전복(Abalone) 데이터셋을 활용해 전복의 신체적 특성을 기반으로 '전복 순살의 무게'라는 연속형 숫자를 예측하는 지도학습 회귀(Regression) 실습

실생활과 데이터의 연결: 전복의 구매 단위('미')나 순살 비율 등 실제 농수산 시장의 생활 밀착형 문제를 데이터 변수(전체 무게, 껍질 무게, 길이 등)로 추상화하고 이해하기

회귀(Regression) 개념의 이해: 분류(Classification)와 달리 연속적인 수치(무게)를 예측하는 머신러닝 알고리즘의 원리를 오렌지3 시각화 환경에서 습득하기

데이터 전처리: 전체 무게 대비 순살 무게 비율과 같은 변수 간 상관관계를 탐색하고, 어떤 특성(Feature)이 예측 목표(Target)에 가장 큰 영향을 미치는지 데이터 분석하기

머신러닝 실습: 데이터 불러오기 → 변수 설정(Target 지정) → 모델 학습→ 성능 평가(MSE, R2 등)

분류대상 데이터역할 및 이유
Data Sample훈련 데이터
(Train Data)		• 모델(Linear Regression) 패턴 학습 목적
• 예측 평가용 데이터로 사용 시 결과 왜곡 발생
Remaining Data테스트 데이터
(Test Data)		• 학습에 미포함된 미지의 데이터로 모델 성능 평가
• 과적합(Overfitting) 방지: 단순 암기 여부 검증
• 평가 객관성 확보: 학습 데이터 재사용 시 발생하는 평가 편향 제거
• 실전 환경 모사: 실제 운용 환경과 동일한 조건 제공

[추가 개별 활동] 학번별로 부여된 과제를 추가로 진행하기

학번과제 주제 및 오렌지3 수행 내용
01회귀 알고리즘 4종 비교: Linear Regression 외에 Tree, Random Forest, KNN을 Test & Score 위젯에 동시 연결하여 4개 평가지표 비교하기
02특성 중요도 분석: Rank 위젯을 연결해 전복 순살 무게 예측에 가장 큰 영향을 미치는 변수 Top 3 탐색하기
03독립변수 제어 분석: Select Columns 위젯으로 껍질 무게, 전체 무게 등 특정 변수를 하나씩 제외하며 모델 정확도(R2) 변화 관찰하기
04살수율 변수 생성: Feature Constructor 위젯으로 (순살 무게 / 전체 무게) 파생 변수를 만들어 새로운 예측 모델 구축하기
05예측 오차 시각화: Predictions 위젯과 Scatter Plot을 연결하여 X축을 '실제 순살 무게', Y축을 '예측 순살 무게'로 놓아 오차가 큰 데이터점 찾아내기
06이상치 제거 전후 비교: Outliers 위젯으로 극단값을 제거하기 전과 후의 R2 점수 및 MSE 개선율 비교하기
07학습/테스트 데이터 비율 실험: Data Sampler 위젯으로 Train:Test 비율을 5:5, 7:3, 9:1로 변경하며 평가 지표의 변화 관찰하기
08Cross-Validation 적용: Test & Score 위젯에서 K-fold Cross Validation(k=5, 10)을 적용해 데이터 분할에 따른 성능 안정성 확인하기
09성별(Sex)에 따른 회귀 분석: Data Sampler 또는 Select Rows로 수컷, 암컷, 유체(Infant) 데이터를 분리해 각각의 순살 무게 예측 모델 만들기
10상관관계 산점도 분석: Scatter Plot 위젯에서 전체 무게와 순살 무게 간의 상호작용 및 분포 시각화하기
11나이(Rings) 예측 회귀: 타겟(Target) 변수를 '순살 무게'에서 전복의 나이를 나타내는 'Rings(나이테)'로 변경하여 회귀 모델 새로 만들기
12전복 크기 분류 문제로 전환: Continuize 또는 Discretize 위젯으로 순살 무게를 '대/중/소' 3단계 범주로 만들어 Decision Tree 분류 모델 구성하기
13Lasso / Ridge 회귀 비교: Linear Regression 속성 설정에서 L1(Lasso)과 L2(Ridge) 규제를 각각 적용해 오버피팅 방지 효과 확인하기
14k-Means 군집화: k-Means 위젯으로 전복들을 군집(Cluster)화한 뒤, 각 그룹별 평균 순살 무게 차이 비교하기
15의사결정나무 시각화: Tree Viewer 위젯으로 전복 순살 무게가 특정 값 이상이 되기 위한 조건문(If-Then Rule) 추출하기
