1.4.1. 결측치 dropna 함수로 처리

dropna: Drop+ NA

  • Drop (버리다 / Drop out): 필요 없는 요소 제거
  • NA (Not Available / Not Applicable): '결측치(데이터 없음)'
  • dropna함수로 결측치가 포함된 행 삭제하기 ex) df = df.dropna()
  • 결측치 데이터를 다음 값으로 채우기 ex) df = df.fillna(method='bfill')
  • 결측치 데이터를 이전 값으로 채우기 ex) df = df.fillna(method='ffill')
  • 결측치 데이터를 임의의 값(0)으로 대체하기 ex) df['평균기온'].fillna(0,inplace=True)
  • 결측치 데이터를 평균값으로 대체하기 ex) df['평균기온'].fillna(df['평균기온'].mean( ),inplace=True)

seaborn 선형 회귀 시각화 함수(regression plot)
• 두 연속형 변수 간의 관계(양의 상관관계, 음의 상관관계 등)를 직관적으로 파악할 수 있음.

fig, axs, ax의 관계

  • fig (Figure): 전체 차트의 창(2x2)

  • ax (Axes): axs 배열 안에 들어 있는 개별 서브플롯 하나하나

1.8. 피처(훈련) 데이터와 레이블(정답) 데이터 분리하기

피처(훈련) 데이터만 따로 빼내는 이유

  • 지도학습 알고리즘(fit() 메서드)은X(문제)를 넣었을 때 y(정답)가 나오도록 학습함.
  • 피처와 레이블이 섞여 있으면 무엇을 기반으로 하는지 알고리즘이 인식할 수 없음.
  • 정답 정보(레이블)가 입력 데이터(피처)에 섞여 들어가면, 시험을 치르기도 전에 답안지를 보여주는 꼴이 되어 모델이 과적합되거나 실제 상황에서 제대로 예측하지 못하게 됨.

MSE (Mean Squared Error): 0.356
• 의미: 예측값과 실제값 차이(오차)를 제곱하여 평균낸 값
• 해석: 이 수치는 0에 가까울수록 모델의 성능이 좋다는 뜻. 다만, 오차를 제곱했기 때문에 실제 데이터의 단위보다 부풀려져 있어 직관적으로 '얼마나 틀렸나'를 느끼기엔 조금 어려움.


RMSE (Root Mean Squared Error): 0.596
• 의미: MSE에 루트를 씌운 값
• 해석: 제곱으로 부풀려졌던 오차를 다시 원래 데이터와 비슷한 단위로 맞춘 것으로, "이 모델은 예측할 때 평균적으로 약 0.596 정도의 오차를 내고 있다"고 해석할 수 있음.


R2score (결정계수, R2): 0.583
• 의미: 모델이 데이터의 변동성을 얼마나 잘 설명하는지를 나타내는 지표. (0~1 사이 값)
• 해석: 0.583(이 모델이 전체 데이터의 흐름을 약 58% 정도 설명하고 있음.)
◦ 1.0: 완벽한 예측
◦ 0.7 이상: 꽤 괜찮은 모델
◦ 0.5~0.6: 나쁘진 않지만, 개선의 여지가 많은 모델 (현재 상태)


종합 평가
이 모델은 데이터의 전체적인 경향을 절반 조금 넘게(58%) 설명하고 있으며, 예측 시 평균적으로 0.6 미만의 오차를 보일 수 있음.

2.14. boxplot + stripplot 시각화

코드입력_13

2015년부터 연도에 따른 강수량을 월별로 색상을 다르게 시각화하기

그림 사이즈: 20x5, 범례를 그림 박스 밖으로 표시하기

df_2015 = df_rain[df_rain['년'] >= 2015]
plt.figure(figsize=(20, 5))

# boxplot 그리기
sns.boxplot(
data=df_2015,
x='년',
y='강수량',
hue='월',
palette='husl',
showfliers=False, # 중복 방지를 위해 박스플롯의 기본 이상치는 숨김.
dodge=True # 월별로 색상을 다르게 하기(dodge=True)
)

# stripplot 그리기
ax = sns.stripplot(
data=df_2015,
x='년',
y='강수량',
hue='월',
palette='husl',
dodge=True,      # 박스 위치에 맞게 점을 배치
jitter=True,     # 점들을 약간 흩뿌림
size=1,          # 점 크기 조절
alpha=0.5,       # 점의 투명도 조절 (이미지처럼 은은하게)
linewidth=0.5    # 점의 테두리 굵기
)
plt.legend(bbox_to_anchor=(1, 1), loc='upper left')
plt.xlabel('년')
plt.ylabel('강수량')
plt.show()
